## 3. Event-completion analysis (primary bar, computed from local `candles_15m`)

**Event marker actually computed** (not fabricated): for each trade, recompute the mean-reference on the local 15m series — `SMA20(closes)` (which is exactly the BB mid used by `bb_bounce`/`bb_bounce_v2`, `BB_PERIOD=20`, `BB_STDDEV=1.8`, and a stand-in for z=0 in the z-score family). Counterfactual exit = the **first 15m candle whose close crosses the SMA20 in the trade's favor and whose close lands at/before the actual exit** (no look-ahead, no exit after the real close). If no such candle → **censored**, counterfactual = actual (rule never fires).

Three pre-registered bars tested:
- **A (primary): exit at SMA20 close-cross** (event: price returns to the mean)
- **A′ (sensitivity): exit at SMA20 touch** (fill at the mean price on high/low touch)
- **B: exit when |z| ≤ 1, z=(close−SMA20)/σ20** (event: z normalizes) — plus a strict variant where entries that are *already* normalized exit at entry (0pp)

**Population split by measurement, not by outcome:**
- `entered_past_mean` n=**146** — entry already on/past the far side of the 15m mean → event already resolved at entry, counterfactual = exit at entry (0pp)
- `clean_resolved` n=**126** — entered before the mean, event fired → counterfactual = crossing close
- `clean_censored` n=**119** — entered before the mean, **mean never re-touches before the actual exit** → counterfactual = actual (identical)
- skipped n=2 (no 15m warmup)

## 4. Verdict

### **REFUTES S2**

Evidence (all numbers above, reproducible):
1. **No bar, no split shows event-exit > actual by a significant margin.** Primary bar A on the clean population: Δ = **−0.0071pp/trade**, sign **61/64 p=0.858**, Wilcoxon **p=0.985**, 95% CI **[−0.078, +0.064]**.
2. **Where a result is significant it favors the ACTUAL exit**: strict z-bar Δ −0.0476pp, sign **131/207, p=4.2e-5** (in-sample); A′ touch sign **128/173, p=0.011**. Both OOS-null (p=0.219 / 0.73).
3. **Economically trivial even at the CI bound**: event exit USD delta = **−$0.28** (clean, n=230) / **−$0.12** (full, n=372) over 90 days; CI upper bound +0.064pp/trade on a median `amount_usdt` of **$11.10** (mean $12.14, n=393) ≈ **$0.007–0.021/trade** (unlevered / levered-at-median-3x) — noise at any fee level.
4. **The rule is inert where it matters**: 119/245 (49%) clean trades never re-touch the mean (censored, Δ=0 by construction), and 25/45 of the cut-loser/hard_max_loss exits are in that censored bucket.
5. **OOS leg is separately INDETERMINATE** (n=52 clean, Δ +0.049pp, CI [−0.031,+0.129], p=0.42) — it cannot confirm the thesis, and the pooled in-sample significant results point the other way.

### Recommended next step: **DROP — no shadow, no code**

Per `automatic-implementation`, a shadow would ship OFF, log the counterfactual, and flip only on CEO approval. Not warranted here because:
- the pre-registered bar that would justify any rollout (`Δ ≥ +0.10pp/trade` sustained) is **outside the 95% CI** of the measured effect (upper bound +0.064pp) — we would be logging noise;
- the MR cohort has closed **0 trades since 2026-11-01** (0 in last 14d, 19 in last 30d) — a live shadow collects ~nothing today.

If the CEO still wants a signal on this, the only defensible version is a **log-only counterfactual** (no exit behavior change): flag every open MR trade when a 15m close crosses SMA20 in favor while unrealized pnl > 0, write `would_exit_at_event` to `_signal_metadata`, pre-registered bar = **Δ ≥ +0.10pp/trade over n ≥ 200 counterfactuals**, auto-drop if the first 200 show Δ ≤ 0.

**Redirect the work item instead to the entry-side finding:** 146/391 (37.3%) of "mean-reversion" trades entered with price **already past the 15m mean** (for those, an event-completion rule would never have entered/exits at entry: sign 57/89, p=0.010 in favor of *not* being in them in the first place; sample `_signal_metadata` shows `bb_position` 0.69/0.85, `z_score` +0.76 on LONG, `is_stale: true`, `staleness_minutes` 1.2). That is signal decay at execution, and it is upstream of, and larger than, the exit question. Suggested next work item: **S2-adjacent — staleness/gap gate at entry for MR sources** (measure `gap_at_entry` and `staleness_minutes` vs outcome on the same 393 trades before proposing any filter).

## 5. Caveats

1. **Event definition is a proxy, not per-signal.** Uniform `SMA20(15m)` / `σ20(15m)` applied to all sources. `bb_bounce` v1 and `coiled_spring`/`range_reversion`/`oversold_bounce` actually fire on **5m** candles; `hzscore` uses multi-TF z (4h/1h/15m); `oversold_bounce` uses `Z_LOOKBACK=20` on 5m. Per-signal references were **not** recomputed — 15m SMA20 is the closest computable stand-in for "the mean" across the whole 90d window.
2. **5m data cannot cover the sample**: `candles_5m` retention starts 2026-10-20 → only 19/393 trades are 5m-faithful. `candles_15m` covers 2026-08-21→now (391/393 trades). 1m was only available from `price_history` (2026-09-27→, 88/95 test trades).
3. **Counterfactual is gross and single-exit**: no fees, no slippage, no partial exits, no trailing logic; comparisons are unlevered pp (`pnl_pct` in the DB is levered — verified `pnl_pct = gross × leverage`, median ratio = leverage). USD conversion uses `scale = pnl_usdt/gross` and drops 19/393 trades with `|gross|<0.05%`.
4. **OOS power**: test side is only 52 clean trades (the last-14d split requested in the brief has **n=0** because MR sources stopped closing trades on 2026-11-01); a split of train `<2026-09-28` / test `≥` was used — both sides ≥30 on the full pool (298/93), clean side 193/52.
5. **Clean/full split is a definition choice, not an outcome split**: `entered_past_mean` trades (n=146) are reported both ways (full-strict and excluded). Neither reading supports S2.
6. MFE timing uses 15m highs (no `mfe_time` column exists); an MFE that occurred inside the entry/exit candle but between bar boundaries is invisible at 15m.
7. **Reproducibility**: 2 trades skipped (token `AR`, no warmup); all other numbers are deterministic given the reproduce blocks below.

#   groups: resolved=126 censored=119 entered_past_mean=146
#   A CLEAN n=245 mean=-0.0071pp 95%CI=[-0.0781,+0.0640] sign +61/-64 p=0.8581

import sqlite3, subprocess, datetime as dt
import numpy as np
from scipy import stats
from paths import CANDLES_DB
MR = "(signal ILIKE '%bb_bounce%' OR signal ILIKE '%bb-bounce%' OR signal ILIKE '%hzscore%' OR signal ILIKE '%range_reversion%' OR signal ILIKE '%coiled_spring%' OR signal ILIKE '%coil_spring%' OR signal ILIKE '%return_exhaustion%' OR signal ILIKE '%oversold%bounce%')"

con = sqlite3.connect(CANDLES_DB)
def sma(c,i,per=20):
    w=c[i-per+1:i+1]
    return sum(w)/per if len(w)>=per else None
G={'entered_past_mean':[], 'clean_resolved':[], 'clean_censored':[], 'skip':[]}
for l in out.strip().split('\n'):
    p=l.split('\t')
    if len(p)!=6 or not p[4] or not p[5]: continue
    tok,dirn,ot,ct,entry,exitp = p

    gross=(float(exitp)-e)/e*100*(1 if L else -1)
    ots=int(dt.datetime.fromisoformat(ot).timestamp()); cts=int(dt.datetime.fromisoformat(ct).timestamp())
    rows=con.execute("SELECT ts,close FROM candles_15m WHERE token=? AND ts>=? AND ts<=? ORDER BY ts",(tok.upper(),ots-21*900,cts)).fetchall()
    if len(rows)<21: G['skip'].append(gross); continue
    ii=next((k for k,r in enumerate(rows) if r[0]<=ots<r[0]+900), None)
    if ii is None or ii<20: G['skip'].append(gross); continue
    cl=[r[1] for r in rows]; m0=sma(cl,ii)
    if m0 is None: G['skip'].append(gross); continue
    if not ((e<m0) if L else (e>m0)): G['entered_past_mean'].append(0.0-gross); continue

    for k in range(ii,len(rows)):
        if rows[k][0]+900>cts: break          # cf fill must precede actual exit

        if m is None: continue

    cf=((ev-e)/e*100*(1 if L else -1)) if ev is not None else gross
    G['clean_resolved' if ev is not None else 'clean_censored'].append(cf-gross)
CLEAN=G['clean_resolved']+G['clean_censored']
d=np.array(CLEAN); n=len(d); se=d.std(ddof=1)/np.sqrt(n); t=stats.t.ppf(0.975,n-1)
pos=int((d>1e-9).sum()); neg=int((d<-1e-9).sum())
print(f"usable={sum(len(v) for k,v in G.items() if k!='skip')} skip={len(G['skip'])}")
