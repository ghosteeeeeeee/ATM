## 1. Method (what the tool actually does)

`scripts/neighbor_step_sweep.py` (`--help` documents everything below):

- **Data, local only:** one read-only SELECT on the PostgreSQL brain DB `trades` table (SQL + bind params printed on every run, `ORDER BY open_time, id` for run-to-run determinism) + the local sqlite candles DB opened `mode=ro`, tiered `1m → 5m → 15m → 1h → 4h` with a coverage check (the 1m/5m tables only hold the last ~30 days; 15m/1h/4h cover the full window; per-run tf mix is printed). Import via `from paths import *`; constants imported from `hermes_constants` at runtime — the script contains no current-value literals.
- **Window:** 2026-08-10 00:00:00 UTC → 2026-11-08 21:00:00 UTC (90d), 3184 closed trades.
- **Grid (CLI params, step sizes justified in `--help`):**
  - speed ±2×5 → 30/35/**40**/45/50 — step 5 = `self_learner.py:85` tuner step (range 30–60); matches the 30→40 history.
  - SL ±2×0.002 → 0.011/0.013/**0.015**/0.017/0.019 — step 0.002 = `self_learner.py:102` tuner step (range 0.008–0.025); matches the 1.2→1.3→1.5 history.
  - K ±2×0.25 → 1.5/1.75/**2.0**/2.25/2.5 — no tuner entry; half of the last real move (1.5→2.0, `hermes_constants.py:722`) and contains both values the CEO actually tried (1.5 prior, 2.5 tried-and-reverted).
- **Metric:** net PnL (USDT) of the counterfactual book at each grid point, with n, WR, and intervals. The verdict stage uses the **paired delta** d = metric(neighbour) − metric(current):
  - **SL/TPK (bound mode):** a hard envelope built per trade by pairing the *same hypothetical world* across grid points (die-vs-die, horizon-vs-horizon) and conservatively crossing labels present on only one side; duplicate arm values are deduplicated so bookkeeping can't fake a swing.
  - **SPEED (exact mode):** an exact recount of the recorded book; the **bootstrap 95% CI is the interval used in the verdict tests** (point estimates alone are not treated as certainty — code-review finding #4).
- **Verdict rules (pre-stated, printed before the data):** collapse bar = max(0.5×|current metric|, $1) (the $1 floor stops the bar degenerating near a zero book — review finding #9). SPIKE = some ±1 neighbour has d_hi < 0 **and** d_hi < −bar. HILL = every ±1 neighbour has d_lo ≥ −bar. Otherwise INDETERMINATE. SPEED additionally requires n_swung ≥ `--min-n` 30 per ±1 neighbour; SL/TPK have no n gate because their interval is a hard envelope, not an estimate (n_swung reported anyway).
- **Sample-size discipline (THE PATTERN):** n printed for every number; n_swung (trades whose counterfactual actually differs between a grid point and current) is the identifying sample; Wilson 95% CIs on WR, seeded bootstrap 95% CIs on sums (seed 20261108, resample identity includes the grid point); engine-vs-actual reproduction gap printed with every SL/TPK verdict as the model-conditional caveat; resolution stats printed so an indeterminate could cite the exact data gap.

### Counterfactual models (one line each; full bias list in §4)

- **SPEED:** admitted set at threshold t = recorded SHORT trades with `speed_percentile ≥ t` (the field actually present in `_signal_metadata`; inventory printed at runtime). Δ = exact recount of the swapped trades; CI = bootstrap over the swapped cohort.
- **SL:** each trade's initial stop distance is reconstructed (cohorts: A = pinned at a current/historical era floor via `sl_distance`; B_above = `sl_distance` above floor; **B_evidence = non-trailed stop-out whose recorded fired-stop level is above the floor — conclusive proof the floor never bound (133 trades)**; C = below every floor = explicit-SL/A-B-group paths, unaffected in the primary model). Outcome re-decided from MAE: `mae ≥ new_stop → dies at −stop` (first-barrier argument); widened survivors get their path extended from `close_time` over the candle DB with barriers {new stop, recorded target, 48h horizon}.
- **TPK:** new target from the recorded `target` (interior → exact k_atr reconstruction; at-floor/at-cap → envelope; outside the clamps → structural/bypass, K never binds — both models run as primary/sensitivity). TP-touch vs actual-exit ordering resolved from candle first-touch; same-candle ties stay in both envelope arms; the no-candle fallback includes the die-at-stop arm (review finding #6).

## 4. Methodology + approximation caveats (direction of bias)

**`SIGNAL_FILTER_SPEED_MIN`**
1. Strict-enforcement counterfactual on a gate that is porous in production (AMBIGUOUS penalty; 342 post-raise sub-40 trades) — "admission" is hypothetical. [bias unknown]
2. Signals speed-blocked entirely never appear in `trades`; below-threshold sets only re-weight recorded trades. [unknown; porosity count bounds it]
3. Execution-time speed (gate) vs signal-time `speed_percentile` (DB). [noise]

**`ATR_SL_MIN`**
1. Trailing/PM_TRAIL path assumed unaffected by a changed initial floor. [widening: overstates profit-locking; narrowing: understates it]
2. Uniform floor across the window although history ran 1.2/1.3. [by design — this is what "set the constant to v" means; era-only validation run in §2.2 isolates it; residual model error ≈ $1.3]
3. `sl_distance` is an A/B-group field (`brain.py:594-597`), not a guaranteed initial-stop record: non-stop-out trades take their initial stop from it, so where the ATR stop actually exceeded the floor this overstates the floor's reach. Non-trailed stop-outs carry conclusive evidence (the fired level, 133 trades → B_evidence cohort). [residual bias: trail/other exits whose initial stop exceeded the floor, direction unknown]
4. Below-floor explicit-SL trades unaffected (primary) — sensitivity variant treats them as floor-pinned. [both HILL]
5. Widened-stop continuation replicates only {stop, TP, horizon} barriers — no trailing, no hard exits. [widens dispersion]
6. `mae ≥ new_stop → dies at −stop` first-barrier argument; same-candle tie at the finest available resolution ignored. [slightly optimistic for stops]
7. **`ATR_SL_MIN` feeds the entry R:R gate** (`risk_reward_engine.py:604,640,753`) — admission-side effects of a changed floor are NOT in this counterfactual. [missing blocked-cohort PnL, direction unknown — this is the main unmeasured channel for SL]

**`ATR_TP_K_MULT`**
1. Interior targets assumed ATR-derived (structural rr_engine targets misread as ATR ones). [direction unknown; interior only]
2. Below-floor target population is a mixture of era-clamped ATR targets (ATR_TP_MIN was 0.8 then 1.3 inside the window — K bound) and structural targets (K never bound); cannot be separated from the DB → two models run, verdict identical. [disagreement ≤ $0.65]
3. TP-first ordering from candles (finest available, 1m–15m tiered); same-candle ties resolved pessimistically in one envelope arm and optimistically in the other. [true value inside the envelope]
4. Continuation past an actual TP exit: {stop, TP, horizon} only, no trailing; the no-candle fallback includes the die-at-stop arm. [widens dispersion]
5. 17 target-crossing-without-exit trades pinned to actual. [conservative]
6. Admission side: none — grep-verified no admission-path consumer.
