## 6. Deviations / decisions (stated per contract — no value deviations)

1. **ε formula**: spec's literal `5bps·√(H_min/60)` yields 2.5/5/10, contradicting the
   fixed table 5/10/20 in the same clause (task also pins 5/10/20). Implemented as
   `5·√(H_min/15)` → **5/10/20 exactly as specified**; the fixed table governs.
2. **`predict --backfill N`** (default **0** = exact spec timer behavior): opt-in flag so
   `resolve`/`score` have day-one out-of-sample calls; each backfilled call is trained
   only through its own anchor (no lookahead). Used `--backfill 200` once for evidence.
3. **1m features omitted** (spec §2.2 explicitly allows omit-with-disclosure): 1m depth
   ≈30d leaves no EMA200/300 warmup headroom at window start, and would push features
   to ~75 > the 40–70 target. 4h tier omits the 1h-momentum feature (window < tier
   interval — impossible). 5m tier depth is 32.8d (vs 90d on 15m/1h/4h) — it binds the
   backfill depth (67/66/16 calls with full 30d windows).
4. **Query line adds a status suffix** (`VALIDATED/UNVALIDATED/PENDING`) — required by
   spec §2.5 "output says so in the query line".
5. **Model format: joblib** (spec allowed joblib/pickle); state/report formats per §2.6.
6. **Collector lag disclosed**: `candles.db` marks `is_closed=1` about one bar period
   after the true close → calls are logged when the anchor bar is marked closed, and
   `resolve` joins only from `is_closed=1` (never mid-bar). Predictions use only
   closed-bar features ≤ anchor; no post-anchor data enters any fit.
7. **Timer not enabled** (freq-shadow "enable pending deploy" precedent — CEO deploys).
8. **Spec §2.7 protocol gap**: mandatory code-review + bug_hunter subagent rounds were
   **not run** — this builder is a subagent at max delegation depth and cannot spawn
   them. Parent should run code review + bug_hunter before trusting v1 beyond
   informational use. (Self-review done; two real bugs found & fixed pre-commit: RSI
   computed but never added to the feature frame; backfill depth anchored on first
   fetched row instead of last-starting tier.)
