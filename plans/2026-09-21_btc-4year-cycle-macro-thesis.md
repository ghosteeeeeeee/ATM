### The Pattern

```
BOTTOM → 3 years BULL → PEAK → 1 year BEAR → BOTTOM → repeat

Each bull run has 9 steps:
  Steps 1-3: Slow grind (2-3 months each)
  Steps 4-6: Faster acceleration (1-2 months each)  
  Steps 7-9: Parabolic blow-off (weeks, not months)

Volatility profile:
  Early bull: +1.6x, -0.3x corrections
  Mid bull:   +1.6x, -0.5x corrections
  Late bull:  +2.0x, -0.6x corrections (violent swings)
```

### Key Insight

**The $60-65k low (Aug 2026) is the cycle bottom.** If the pattern holds:
- Bull run: Aug 2026 → ~Aug 2029 (3 years)
- Bear market: Aug 2029 → ~Aug 2030 (1 year)
- Next bottom: ~Aug 2030

**As long as BTC stays above the cycle support level, the bull run is intact.** Crashes are buying opportunities, not trend changes.

## How to Use This Information

### 1. LONG Bias for 2-3 Years

The macro thesis says LONG for the next 2-3 years. This means:
- **Default direction: LONG** — every dip is a buying opportunity
- **SHORT only for hedging** — don't fight the macro trend
- **Position sizing: larger in LONG** — the wind is at your back

### 2. Survive the Volatility

The bull run has violent swings:
- Up 1.6x, then give back 0.5x
- Swings get more violent toward the peak
- Each correction is deeper than the last

**Trading implication:** Don't get stopped out on corrections. Use wider stops in LONG positions. The trend is your friend.

### 3. Fibonacci Price Targets

The 9 steps can be mapped to Fibonacci extensions:
- Step 1-3: 0.236, 0.382, 0.5 extensions
- Step 4-6: 0.618, 0.786, 1.0 extensions
- Step 7-9: 1.272, 1.618, 2.618 extensions

### 4. Cycle Support Level

The key question: **What is the minimum price that keeps the bull run intact?**

If the pattern holds, the cycle support is likely around:
- Previous cycle peak ($69,000) as support
- Or the 0.618 Fibonacci retracement from bottom to current

**This is the "line in the sand" — if BTC drops below this, the thesis is invalidated.**
