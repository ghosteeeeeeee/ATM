## Root Cause Analysis

### Evidence That Signals Are Correct
- VVV LONG (conf=98, dual-source accel-300+ AND rs-s346, hot-set=YES) — still hit SL
- SUI LONG (conf=95, 5x leverage) — signal was right, got stopped out by noise
- The signal sources are working: accel-300+ with RS co-signal is a valid confluence

### The Real Problem: ATR-based SL Too Tight for Low-Vol Assets

Current constants (hermes_constants.py):
```
ATR_SL_MIN = 0.002   # 0.20% floor
ATR_SL_MAX = 0.005   # 0.50% cap
ATR_K_LOW_VOL = 1.0  # k for ATR% < 1%
```

For low-ATR assets:
- SUI: ATR ~0.4% → k=1.0 → sl_pct = 0.4% → at 5x leverage, 0.08% adverse move = stopped
- NEAR: ATR ~0.3% → k=1.0 → sl_pct = 0.3% → at 5x leverage, 0.06% adverse move = stopped
- TAO: ATR ~0.6% → k=1.0 → sl_pct = 0.6% capped at 0.5% → at 5x, 0.10% adverse move = stopped

**Normal market noise (a single small candle) exceeds these stops.**

### VVV Example (best illustration)
- VVV LONG entered at 16.999, SL hit at 16.8145 (PnL = -1.085%)
- Actual price move to hit SL: 0.36%
- At 3x leverage: 0.36% × 3 = 1.08% PnL ✓ (matches)
- SL was 0.5% below entry (ATR_SL_MAX cap)
- Price moved 0.36% against us and that was enough

### Constants vs. T's Directive
T's memory says: MIN_ATR_PCT=0.50%, MAX_SL=2.0%, MIN_TP=0.75%, MAX_TP=5.0%
Running constants show: ATR_SL_MIN=0.20%, ATR_SL_MAX=0.50%

The tighter constants (0.50% cap vs 2.0% cap) are actively losing money.
