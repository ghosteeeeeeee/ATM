# accel-300 Debug Trace — 2026-05-31

## Issue
Manual run of `scan_accel_300_signals()` on all 91 fresh tokens → 0 signals emitted.

## Root Cause Chain

### 1. Staleness gate (bars_since_cross > 10)
The signal requires `bars_since_cross <= 10`. For XLM at bar 698:
- cross_bar = 475 (XLM crossed EMA300 ~223 bars ago)
- bars_since_cross = 698 - 475 = 223 > 10 → REJECTED

Tokens that have been above/below EMA300 for more than 10 bars silently fail this check.

### 2. cond4b marginal acceleration (when bars_since > 3)
When `bars_since_cross > 3`, signal checks `delta_last > delta_prev` (LONG).
If gap growth is decelerating, signal is rejected even if all other conditions pass.

### 3. DASH fires successfully
DASH had `bars_since_cross = 4` → passed staleness gate.
Detected with: gap=0.532%, growth=0.480%, bars_since=4.
Signal written to `signals_hermes_runtime.db`.

### 4. Why signals_runner shows 0
After DASH fires, cooldown is set. No other fresh tokens had valid cross within 10 bars.

```

  → scan_accel_300_signals(prices_dict)
    → detect_accel_300(token, prices) for each token
      → bars_since_cross check (line ~291, >10 → continue)

    → add_signal() → signals_hermes_runtime.db
cooldown set → next cycle: get_cooldown() blocks re-fire
```
