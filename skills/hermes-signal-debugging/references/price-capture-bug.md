# Price Capture Bug — rs.py / signals.json (2026-06-03)

## Symptom

- 56 pending LONG signals in signals.json all have `price=0`
- 38 executed signals all have `entry_price=None`, `pnl_pct=None`
- 5 out of 59 pending SHORT signals have valid price data

## Root Cause

The compactor (signal_compactor.py) has a price gate that rejects signals with `price <= 0` from reaching hot-set. Every LONG signal generated by rs.py arrived at the compactor without a valid price, so they are filtered out before ever reaching hot-set.

The data capture issue is in rs.py's `detect_rs_signal()` — the `price` field is not being populated with the current price at detection time. SHORTs occasionally have price captured (5/59) but LONGs never do (0/56).

## Impact

- No LONG signals ever enter hot-set — even though 56 are pending
- No trade P&L is recorded back to signals.json after execution
- Guardian cannot reconcile executed trades back to signal source for performance analysis

## Investigation

```python
# Check pending signals for price data
import json
with open('/var/www/hermes/data/signals.json') as f:
    data = json.load(f)
pending = [s for s in data['signals'] if s.get('decision') == 'PENDING']
longs = [s for s in pending if s.get('direction') == 'LONG']
shorts = [s for s in pending if s.get('direction') == 'SHORT']
print(f"LONGs with price>0: {sum(1 for s in longs if s.get('price', 0) > 0)}/{len(longs)}")
print(f"SHORTs with price>0: {sum(1 for s in shorts if s.get('price', 0) > 0)}/{len(shorts)}")
```

## Not a rs.py Direction Bug

rs.py signal direction logic is symmetric and correct. The patches applied (lines 553-563, 616-626) are clean. The price capture failure is a **data pipeline issue** — the signal source is valid, but the price field isn't being written at detection time.

## Fix Required

1. Trace where `price` is set in the signal dict in rs.py `detect_rs_signal()`
2. Verify the caller is passing current price into `detect_rs_signal()`
3. Check if the price dict lookup for the token returns None/0 at detection time (race condition?)
