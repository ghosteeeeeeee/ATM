# RS Signal Collapse — Confluence False Negatives (2026-06-15)

## The Problem

Multi-level RS signals (e.g., `rs-r12,rs-r8`) look like they have 2 signal sources, but after the collapse logic they become 1 unique type → BLOCKED at confluence gate.

### Collapse Logic (signal_compactor.py ~541-565)

```python
def _signal_type_key(part: str) -> str:
    part = re.sub(r'-broken$', '', part)          # rs-s-broken → rs-s
    part = re.sub(r'^rs-[sr]', 'rs', part)         # rs-r12 → rs, rs-s86 → rs
    return re.sub(r'\d+$', '', part) or part        # strip trailing digits
```

**Result:** `rs-r12,rs-r8` → both parts become `rs` → `{'rs'}` = 1 unique type → BLOCKED.

## Root Cause

The collapse logic was designed to prevent fake diversity (same signal type at different timestamps counted as separate sources). But it also kills legitimate multi-level RS signals where price touched multiple distinct levels.

A true multi-source RS signal would need BOTH `rs-s` (support) AND `rs-r` (resistance) — different signal families — to pass. Multiple resistance levels at different bars all collapse to the same `rs` family.

## Why RS Signals Are Sparse

RS signals are generated by `signals/rs.py`. Key constraints:
- `RS_DECIDER_MIN_TOUCHES = 80` — decider approval threshold
- `RS_TOUCH_HARD_CAP = 120` — block at 120+ touches (exhausted level)
- `RS_MIN_CONFIDENCE = 50` floor, `RS_MAX_CONFIDENCE = 88` cap
- `RS_DECIDER_CONF_PENALTY = 15` per touch below threshold
- `RS_DECIDER_CONF_FLOOR = 60` — below this → blocked

To fire, a level needs 80+ touches. Most levels never reach this.

## The 5-Minute Expiry Window

All single-source signals (accel-300 OR rs alone) go PENDING. After 5 minutes without a co-signal, they expire.

```
PENDING → (no co-signal in 5 min) → EXPIRED
```

## Two Distinct Issues

1. **RS Signal Collapse** (false negative): Multiple RS levels all collapse to `rs` → blocked. Multiple resistance levels (rs-r12,rs-r8) = same family = 1 type.

2. **Signal Timing Gap** (systemic): accel-300 fires frequently, RS fires rarely — they rarely coincide within 5 min. Single-source signals expire before co-signal arrives.
