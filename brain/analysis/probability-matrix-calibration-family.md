## 1. Rolling-origin fold design (§4)

- each fold: train `30d` -> test `7d`, stepping forward `7d`; cells admitted from that fold's train ONLY (n >= 15); frozen blended predictor p = clip((n*wr_raw + 10*0.50)/(n+10), 0.01, 0.99) — always blended, regardless of store tier
- 5 folds fit in 90d (spec requires >= 3); test folds are disjoint + contiguous, so every test trade is scored exactly once

## 7. Caveats

- **Signal churn (measured, §9)**: labels like `jup_yolo_mirrored` are born mid-window; new cells are UNCALIBRATED (n<15) by design, so OOS coverage is structurally low. n_min is never loosened to chase coverage.
- **In-sample labels**: §6 store view and anything computed on the same window it was fit on is descriptive, not evidence; only §4 folds are OOS.
- **Observational bias**: cells condition on trades that survived existing gates; a gate that changes admission changes the population (P1 counterfactual is the honest test, §6 of the spec).
- **Clustering**: all significance is cluster-robust (cluster=family, CR1, cluster_t.py math); naive p-values are optimistic and not used.
- **small-G (G=5/6<10): cluster inference unreliable — treat p/CI as indicative (limbs a,b,c)**
- **pnl_usdt == 0** counts as non-win (y=0); matches streak_analysis.
- **Regime axis**: volatility_regime with regime fallback (cell_stats.py:80 parity); trades.regime is a different vocabulary and only a fallback.
- **Confidence semantics**: final_confidence is the raw invented confidence (§1.2), known to invert PnL — beating it would not make it a probability.
- Unmatched signal keys in the store join: 0.0% of window trades — counted and shown in the normalization section, never dropped.
