## Claim 2: Chikou Span Comparison

> The Chikou span compares future close (closes[j+26]) against current close (closes[j]) for momentum confirmation

### Verdict: AGREE
### Confidence: HIGH

**Evidence:** Computation at line 110: `chikou[i - ICHIMOKU_CLOUD_SHIFT] = closes[i]`
This means `chikou[j] = closes[j + CLOUD_SHIFT] = closes[j + 26]`.

At line 194: `chikou > price` where `price = closes[j]`.
So the comparison is: `closes[j+26] > closes[j]` — did price go UP over the next 26 bars?

**Verified with synthetic data:**
- Created 120-bar array `[100, 101, ..., 219]`
- `chikou[0] = closes[26] = 126` ✓
- `chikou[93] = closes[119] = 219` ✓
- `chikou[94] = None` (out of bounds) ✓

This matches the standard Ichimoku interpretation: Chikou span is the current close plotted 26 bars back. In backtesting, we look at bar j and chikou shows what the close was 26 bars later.

## Claim 3: Search Range Accounts for Chikou Backshift

> The search range accounts for Chikou being shifted backward (search_end = n - CLOUD_SHIFT)

### Verdict: AGREE
### Confidence: HIGH

**Evidence:** Line 166: `search_end = n - ICHIMOKU_CLOUD_SHIFT`
Line 167: `if search_end <= ICHIMOKU_SENKOU_B_PERIOD + ICHIMOKU_CLOUD_SHIFT: return None`

With 120 candles: `search_end = 120 - 26 = 94`. The last valid j is 93, where `chikou[93] = closes[119]` (last candle). This is correct — j=94 would need `closes[120]` which is out of bounds.

`search_start = max(52 + 26, 94 - 5) = max(78, 89) = 89`. The search range [89, 94) covers 5 bars. This is sufficient — 9 signals were emitted on live data.
