## Findings

**F-1 (MED) — malformed state entry silently kills trailing for every position, no self-heal.**
`auto_trader.py:410/416` `float(prev['sh'])` raises (`TypeError`/`ValueError`/`AttributeError` for non-dict) *outside* any inner try; the load-time try (`:396-400`) only covers unparseable JSON. Effect (harness-proven): the whole `tweak_structure_fixed` loop aborts → R1 **and** R2 lost for all positions, every cycle; no save on exception → corrupt entry persists → permanent. Survives only as `WARN tweak_structure_fixed failed` at `auto_trader.py:556-559` (run_cycle continues — verified). No current writer emits bad types (both write sites stamp floats+ts), so trigger = manual edit / external write / partial-schema drift.
*Fix direction:* validate/skip malformed entries in `_lag_stop` (`prev` not dict or `prev['sh']` not numeric → treat as birth).

**F-2 (MED) — 2 of 9 armed orders lack `dynamic_sl:false`; mxm will fight the rule on them.**
`data/pending_orders.json`: `btc-ceo-short-ladder-local` (rung 1 — commit claims ladder locked) and `btc-ceo-short-flagfloor` (carries giveback profile, no `dynamic_sl`) → at fire (`--signal ai-trader-pending`, `trade_watchdog.py:1594`) mxm stays active → moves the stop every 1-min pipeline cycle → violates "stops move only on new structure", and mxm re-tightens any `_lag_stop` bump within ~1 min (harness Cii: 74650→74351). Bounded, not a thrash loop — but the structure-lag rule is effectively not enforced on those trades.

**F-3 (MED) — clamp can rescue an already-breached stop instead of letting the break exit.**
`auto_trader.py:412` (`max(want, price*1.001)`) / `:418-419` (`price*0.999`): harness D1/D1b write a CAS with the already-crossed old value → hit-check then sees no breach → trade survives a stop price already took out; subsequent exit ≥0.1% worse (short) or delayed (long). Window = watchdog's 30-min cycle landing in the ≤60 s gap before `position_manager`'s hit-check, with structure-change/birth + clamp binding. Contradicts the stated rule "if that is broken we get taken out". Watchdog has no hit-check before `run_cycle` (`trade_watchdog.py:2154` detect-only, `:2162` tweak, execution later).

**F-4 (LOW) — no cap on bump distance.** Harness D3: stored sh=90000 → stop 90050 while price=74000 (21.7% away). Bounded in normal operation by zigzag spacing + 30-min refresh; unbounded after a watchdog outage (stale entry is used as bump target before the 72h prune runs on save).

**F-5 (LOW) — OR-condition moves stops on irrelevant-swing changes.** `auto_trader.py:426` `cur_sh != prev['sh'] or cur_sl != prev['sl']` — a swing-LOW change bumps a SHORT (harness D4: real write). Usually a no-op (same target), but can write when the price clamp binds differently.

**F-6 (LOW) — CAS failure consumes the structure change.** `auto_trader.py:428-431`: state is recorded even when `_apply_stop` rowcount=0 (stop moved externally between read and write) → the bump to the old structure is skipped until the *next* structure change. Rare for `dynamic_sl:false` trades (only tweak moves those stops), possible with manual edits/concurrent runs.

**F-7 (LOW, operational) — lost-update is only unreachable by topology, not by design.** No file lock; fixed shared tmp name (`:490` `_st_path + '.tmp'`). Normal topology is safe (30-min serialized watchdog; pipeline never calls `run_cycle`), but `auto_trader.py:727-729` has a public `__main__`, and `trade_watchdog_prompt.md` forbids re-running *trade_watchdog.py* while saying nothing about *auto_trader.py* — an agent/manual run during a watchdog cycle interleaves read→modify→write → one structure update lost → a later bump targets a stale structure.

**F-8 (LOW) — stale docstring.** `auto_trader.py:327-347` still documents the replaced R1 (risk-side align / profit-side deepen, ±0.5% cap, "coexist with mxm trail") — contradicts the shipped rule.

**F-9 (INFO) — prune only on dirty save; ts-less/future-ts entries live forever.** Writers always stamp ts (verified both sites), so growth is bounded by trade-id count in practice; a missing-ts entry is never pruned (harness B2d: 500 kept).

**F-10 (INFO) — zigzag window slide.** sh/sl re-derive from a sliding 150-candle 1h window (`structure_analysis.py:31,57`); a swing aging out of the window can change `sh`/`sl` without a new formation → spurious bump trigger. Not observed live; theoretical.
