## Findings

### F-MED-1 — F-1a rejects the ATR-deferral sentinel (`sl=0`/`tp=0`): delayed-entry path is 100% dead-on-arrival
- **Where:** validation `scripts/brain.py:1570-1591` (new) vs producer `scripts/decider_run.py:1107-1108` + cmd build `:1176-1178` (`--sl=0.000000 --target=0.000000`).
- **Blast:** `process_delayed_entries` → LONG rejected on `target 0.0`, SHORT rejected on `sl 0.0` (rc=2). On failure the entry is re-queued (`decider_run.py:1212 still_pending.append`) → retries every cycle until `max_wait` expiry, logging `❌ DELAYED FAILED rc=2` each time; never executes.
- **Mitigation today:** queue `/var/www/hermes/data/pending-delayed-entries.json` = `{"pending": []}`, **no producer exists in the repo** (only `_save_delayed` re-saves) → zero current traffic, fails closed (no money risk).
- **Why it's still a finding:** the path was deliberately revived (BUG-024, Oct 2026) and runs every cycle; `0` is a documented "defer to position_manager" sentinel in this codebase (decider_run.py:3102-3104 comment) — the new validation does not exempt it. Any future queued entry is guaranteed to die.
- **Not fixed (as instructed).** Shape of the fix would be: skip validation for `target<=0`/`sl<=0` (sentinel), keeping the wrong-side checks for real levels.

### F-LOW-1 — `[TP-GAP-FIX]` no-op re-fire at the 0.1% band edge
- **Where:** `scripts/position_manager.py:2774-2796`. When `entry == fill` (re-sync) and target sits inside/at the band (`LONG tgt <= fill×1.001`), `new = fill + |tgt−fill|` equals the old value → target unchanged, but the tag logs **every cycle** (1/min) while the sub-fee target persists (relabel uses strict `<= entry`, so a +0.05%-above-fill TP still labels `manual_tp_hit` net of ~0.09% fees).
- **Reachability:** F-1a forbids sub-0.1% planned distances at add; ATR targets are ≥ MIN_TP_PCT from an onside anchor → only pre-fix stragglers or direct-INSERT rows can reach it (open set currently 0).

### F-LOW-2 — 6dp rounding false-reject band for prices ≤ 3.3e-5
- **Where:** `scripts/decider_run.py:1167/3297` (`round(price,6)`, `round(sl/tp,6)`) vs `brain.py:1570+`. Grid scan: at price ≤ 3.3e-5 the 1.5% level rounds onto entry → `parser.error` despite a structurally valid trade.
