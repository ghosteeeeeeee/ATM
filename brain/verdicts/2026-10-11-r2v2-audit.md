Verdict: AGREE
Evidence: All 4 winners (W, SUSHI, BABY, SYRUP) show exit_reason = close_reason =
  profit-monster-trail, and trailing_activated = true. All 4 losers have trailing_activated
  = false and exited via atr_sl_hit / hard_max_loss ×2 / cut-loser-CL-T1.
Confidence: HIGH
Notes: True but weakly informative — profit-monster-trail is the system's standard
  profitable-exit path; "winners exit via the trailing profit path" is close to definitional.
  It is not evidence of anything exploitable. Real pattern in this set: the 4 winners
  averaged +3.11%, the 4 losers averaged −4.95% — the edge problem is loss size (R:R),
  not win classification.

   `r2v2-long{N}` (hyphen). Same 8-trade set either way, but any analytics keyed on the
   exact string will silently split this signal's history.

   makes signal-time reconstruction impossible for most trades and invites exactly the
   anchor bugs this audit found. Worth backfilling from the signals DB.
