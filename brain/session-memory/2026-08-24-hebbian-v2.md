## Decisions made

1. Chain-fire is advisory only — doesn't block/boost trades yet
2. Min thresholds: lift >= 1.5x, confidence >= 0.60, co_fires >= 5
3. MAX_PER_CYCLE = 3 to prevent pipeline flooding
4. Decay half-life: 14 days
